 What changed in food_bank_builder.py                                                                                                                                                                       
                                                                                                                                                                                                            
 - Browser: it now uses SeleniumBase's CDP mode (sb_cdp) with headed=True and no user-agent or locale override.                                                                                             
 - Profile: a dedicated .chrome-profile/ folder in the project, kept between runs so the DataDome cookie survives. I added it to .gitignore.                                                                
 - Navigation: it opens the homepage, waits about 5 seconds, then goes to /product-search/<term>.                                                                                                           
 - wait_for_access() checks the DataDome iframe:                                                                                                                                                            
   - Hard block: stops immediately with Blocked: … and exit code 1.                                                                                                                                         
   - Slider CAPTCHA, headed: waits up to 120 seconds for you to solve it once; the profile then remembers it.                                                                                               
   - Slider CAPTCHA, headless: stops immediately.                                                                                                                                                           
 - Pagination: clicks #show-more-button until it's gone, then prints Loaded N products and returns the page HTML.                                                                                           
                                                                                                                                                                                                            
 Run it with: uv run python food_bank_builder.py --store "Food Lion" --search bread --headed
